# 二、命名规范

## 2.1 文件命名

| 类型 | 命名方式 | 示例 |
|------|----------|------|
| Vue 组件 | 小写连字符 (kebab-case) | `user-list.vue`、`form-designer.vue` |
| JS 工具文件 | 小驼峰 (camelCase) | `auth.js`、`validators.js` |
| API 文件 | 小驼峰 (camelCase) | `user.js`、`enterprise.js` |
| Vuex 模块 | 小驼峰 (camelCase) | `user.js`、`permission.js` |
| SCSS 文件 | 小写连字符 (kebab-case) | `element-variables.scss` |
| 图片文件 | 小写连字符 (kebab-case) | `logo-blue.png`、`icon-user.svg` |

## 2.2 变量命名

```javascript
// ✅ 正确示例
const userList = []           // 普通变量：小驼峰
const isLoading = false       // 布尔值：is/has/can 开头
const MAX_COUNT = 100         // 常量：全大写下划线
const getUserInfo = () => {}  // 函数：小驼峰，动词开头

// ❌ 错误示例
const UserList = []           // 不要用大驼峰
const loading = false         // 布尔值应有语义前缀
const maxCount = 100          // 常量应全大写
const userinfo = () => {}     // 函数应以动词开头
```

### 布尔值命名前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| is | 是否 | `isVisible`、`isLoading`、`isActive` |
| has | 是否有 | `hasPermission`、`hasChildren` |
| can | 是否能 | `canEdit`、`canDelete` |
| should | 是否应该 | `shouldUpdate`、`shouldRender` |

### 函数命名动词

| 动词 | 含义 | 示例 |
|------|------|------|
| get | 获取 | `getUserInfo`、`getList` |
| set | 设置 | `setConfig`、`setValue` |
| fetch | 请求 | `fetchUserList`、`fetchData` |
| handle | 处理事件 | `handleClick`、`handleSubmit` |
| on | 监听事件 | `onClose`、`onChange` |
| validate | 验证 | `validateForm`、`validateEmail` |
| format | 格式化 | `formatDate`、`formatMoney` |
| parse | 解析 | `parseJSON`、`parseQuery` |
| init | 初始化 | `initData`、`initForm` |

## 2.3 组件命名

```javascript
// ✅ 正确示例 - 使用大驼峰注册，kebab-case 使用
export default {
  name: 'UserList',           // name 属性使用大驼峰
  // ...
}

// 模板中使用
<user-list />

// ❌ 错误示例
export default {
  name: 'user-list',          // name 不应使用 kebab-case
  // ...
}
```

### 组件命名规范

- **name 属性**: 使用大驼峰 (PascalCase)
- **模板使用**: 使用小写连字符 (kebab-case)
- **文件名**: 使用小写连字符 (kebab-case)

### 组件命名示例

| 组件类型 | name 属性 | 文件名 | 模板使用 |
|----------|-----------|--------|----------|
| 列表组件 | UserList | user-list.vue | `<user-list />` |
| 表单组件 | UserForm | user-form.vue | `<user-form />` |
| 详情组件 | UserDetail | user-detail.vue | `<user-detail />` |
| 弹窗组件 | UserDialog | user-dialog.vue | `<user-dialog />` |

## 2.4 Props 命名

```javascript
// ✅ 正确示例
props: {
  // 小驼峰定义
  userId: {
    type: Number,
    default: 0
  },
  isVisible: {
    type: Boolean,
    default: false
  }
}

// 模板中使用 kebab-case
<user-detail :user-id="123" :is-visible="true" />
```

### Props 命名规则

- **定义时**: 使用小驼峰 (camelCase)
- **使用时**: 使用小写连字符 (kebab-case)
- **布尔值**: 以 `is`、`has`、`can` 开头

## 2.5 事件命名

```javascript
// ✅ 正确示例 - 使用 kebab-case
this.$emit('update-data', data)
this.$emit('close-dialog')

// ❌ 错误示例
this.$emit('updateData', data)  // 不要用 camelCase
this.$emit('update_data', data) // 不要用 snake_case
```

### 常用事件命名

| 事件名 | 说明 | 参数 |
|--------|------|------|
| update | 更新数据 | data |
| close | 关闭弹窗/面板 | - |
| confirm | 确认操作 | data |
| cancel | 取消操作 | - |
| submit | 提交表单 | formData |
| reset | 重置表单 | - |
| change | 值变化 | newValue, oldValue |
| select | 选择项 | selectedItem |
| delete | 删除项 | id/item |

## 2.6 API 函数命名

```javascript
// ✅ 正确示例 - 函数名以 Api 结尾
export function userListApi(params) {
  return request.get('user/list', params)
}

export function userCreateApi(data) {
  return request.post('user', data)
}

export function userUpdateApi(id, data) {
  return request.put(`user/${id}`, data)
}

export function userDeleteApi(id) {
  return request.delete(`user/${id}`)
}

// ❌ 错误示例
export function getUserList(params) {}    // 不要省略 Api 后缀
export function UserListApi(params) {}    // 不要用大驼峰
```

### API 函数命名模板

| 操作 | 命名格式 | 示例 |
|------|----------|------|
| 列表查询 | xxxListApi | `userListApi` |
| 详情查询 | xxxInfoApi | `userInfoApi` |
| 新增 | xxxCreateApi | `userCreateApi` |
| 修改 | xxxUpdateApi | `userUpdateApi` |
| 删除 | xxxDeleteApi | `userDeleteApi` |
| 批量删除 | xxxBatchDeleteApi | `userBatchDeleteApi` |
| 导出 | xxxExportApi | `userExportApi` |
| 导入 | xxxImportApi | `userImportApi` |

## 2.7 Vuex 命名

### State 命名

```javascript
// 使用名词，小驼峰
const state = {
  userInfo: null,
  userList: [],
  loading: false
}
```

### Mutation 命名

```javascript
// 使用大写下划线
const mutations = {
  SET_USER_INFO: (state, info) => {
    state.userInfo = info
  },
  SET_USER_LIST: (state, list) => {
    state.userList = list
  },
  RESET_STATE: (state) => {
    state.userInfo = null
    state.userList = []
  }
}
```

### Action 命名

```javascript
// 使用小驼峰，动词开头
const actions = {
  async fetchUserInfo({ commit }, id) {
    // ...
  },
  async updateUser({ commit }, data) {
    // ...
  }
}
```
