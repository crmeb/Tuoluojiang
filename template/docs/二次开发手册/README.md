## 快速导航

### 新增功能模块

1. 阅读 [目录结构规范](./03-目录结构规范.md) 了解模块组织方式
2. 阅读 [Vue 组件开发规范](./04-Vue组件开发规范.md) 编写组件
3. 阅读 [API 接口调用规范](./05-API接口调用规范.md) 定义接口
4. 阅读 [路由配置规范](./07-路由配置规范.md) 配置路由
5. 阅读 [权限控制规范](./08-权限控制规范.md) 添加权限控制

### 修复 Bug

1. 阅读 [代码风格规范](./01-代码风格规范.md) 确保代码风格一致
2. 阅读 [命名规范](./02-命名规范.md) 确保命名正确
3. 参考 [快速检查清单](./附录-快速检查清单.md) 进行检查

### 代码审查

1. 使用 [快速检查清单](./附录-快速检查清单.md) 进行逐项检查
2. 检查 [Git 提交规范](./10-Git提交规范.md) 是否符合要求

## 技术栈

- **框架**: Vue 2.6.14
- **UI 组件库**: Element-UI 2.15.14
- **状态管理**: Vuex 3.x
- **路由**: Vue Router 3.x
- **HTTP 客户端**: Axios
- **CSS 预处理器**: SCSS
- **代码规范**: ESLint + Prettier

---

## 项目结构概览

```
src/
├── api/              # API 接口层
├── assets/           # 静态资源
├── components/       # 全局组件
├── config/           # 业务配置
├── directive/        # 自定义指令
├── filters/          # 全局过滤器
├── icons/            # SVG 图标
├── lang/             # 国际化
├── layout/           # 布局组件
├── libs/             # 工具库
├── mixins/           # Vue 混入
├── router/           # 路由配置
├── store/            # Vuex 状态管理
├── styles/           # 全局样式
├── utils/            # 工具函数
├── views/            # 业务视图
├── App.vue           # 根组件
├── main.js           # 入口文件
├── permission.js     # 路由守卫
└── settings.js       # 全局配置
```
