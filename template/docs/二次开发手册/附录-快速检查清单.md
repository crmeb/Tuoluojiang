# 附录：快速检查清单

## 组件开发检查清单

- [ ] 组件是否有 `name` 属性
- [ ] Props 是否有完整定义（type、default）
- [ ] 对象/数组类型的 default 是否使用工厂函数
- [ ] 是否在 `beforeDestroy` 中清理定时器、事件监听
- [ ] 是否使用 `scoped` 样式
- [ ] Element-UI 样式覆盖是否使用 `::v-deep`

## API 调用检查清单

- [ ] API 函数是否以 `Api` 后缀结尾
- [ ] 是否有 JSDoc 注释
- [ ] 是否正确处理响应状态码
- [ ] 是否处理 loading 状态
- [ ] 是否处理异常情况

## 权限控制检查清单

- [ ] 敏感按钮是否添加 `v-hasPermi` 指令
- [ ] 权限标识是否与后端一致
- [ ] 指令值是否为数组格式

## 代码风格检查清单

- [ ] 是否使用单引号
- [ ] 是否使用 2 空格缩进
- [ ] 语句末尾是否无分号
- [ ] 变量命名是否符合规范
- [ ] 是否有 console.log（生产环境应移除）

## Git 提交检查清单

- [ ] 提交信息是否符合规范格式
- [ ] 是否只提交相关文件
- [ ] 是否通过 lint 检查
- [ ] 是否测试通过

## 新增模块检查清单

- [ ] 是否在 `src/views/` 下创建模块目录
- [ ] 是否在 `src/api/` 下创建接口文件
- [ ] 是否通过后端配置菜单
- [ ] 是否添加权限控制
- [ ] 是否需要创建 Store 模块

## 页面开发检查清单

- [ ] 是否有搜索功能
- [ ] 是否有分页功能
- [ ] 是否有 loading 状态
- [ ] 是否处理空数据状态
- [ ] 是否处理错误状态
- [ ] 敏感操作是否有确认提示
