# 一、代码风格规范

## 1.1 Prettier 配置

项目使用 Prettier 进行代码格式化，核心配置如下：

```javascript
// .prettierrc.js
module.exports = {
  printWidth: 120,      // 一行最多 120 字符
  tabWidth: 2,          // 使用 2 个空格缩进
  useTabs: false,       // 不使用 tab 缩进
  semi: false,          // 语句末尾不加分号
  singleQuote: true,    // 使用单引号
  trailingComma: 'none', // 末尾不加逗号
  bracketSpacing: true, // 对象大括号内加空格
  arrowParens: 'always', // 箭头函数参数始终加括号
  endOfLine: 'lf'       // 使用 lf 换行符
}
```

## 1.2 ESLint 规则

项目使用 babel-eslint 解析器，核心规则：

- **缩进**: 2 空格
- **引号**: 使用单引号
- **分号**: 不强制要求（Prettier 控制为不加分号）
- **console**: 开发环境允许，生产环境建议移除

## 1.3 VS Code 配置建议

在项目根目录创建 `.vscode/settings.json`：

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  },
  "vetur.format.defaultFormatter.html": "none",
  "vetur.format.defaultFormatter.js": "none"
}
```

## 1.4 代码风格示例

```javascript
// ✅ 正确示例
import { getUserList, deleteUser } from '@/api/user'

export default {
  name: 'UserList',
  data() {
    return {
      list: [],
      loading: false,
      pagination: { page: 1, limit: 15 }
    }
  },
  methods: {
    async getList() {
      this.loading = true
      const res = await getUserList(this.pagination)
      if (res.status === 200) {
        this.list = res.data.list
      }
      this.loading = false
    }
  }
}

// ❌ 错误示例
import { getUserList, deleteUser } from '@/api/user';

export default {
  name: 'UserList',
  data() {
    return {
      list: [],
      loading: false,
      pagination: { page: 1, limit: 15 },
    };
  },
  methods: {
    async getList() {
      this.loading = true;
      const res = await getUserList(this.pagination);
      if (res.status === 200) {
        this.list = res.data.list;
      }
      this.loading = false;
    },
  },
};
```

## 1.5 格式化命令

```bash
# 格式化所有文件
npm run prettier

# 格式化指定文件
npx prettier --write src/views/user/index.vue

# 检查格式（不修改）
npx prettier --check src/
```

## 1.6 ESLint 检查

```bash
# 检查代码规范
npm run lint

# 自动修复
npm run lint --fix
```
