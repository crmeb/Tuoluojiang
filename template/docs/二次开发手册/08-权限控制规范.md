# 八、权限控制规范

## 8.1 权限体系

系统实现三层权限控制：

| 层级 | 实现方式 | 控制粒度 |
|------|----------|----------|
| 路由级 | 后端动态菜单 | 页面级别 |
| 按钮级 | v-hasPermi 指令 | DOM 元素 |
| 角色级 | v-permission 指令 | DOM 元素 |

## 8.2 按钮级权限（v-hasPermi）

```vue
<template>
  <!-- 单个权限 -->
  <el-button v-hasPermi="['asset:create']" type="primary" @click="handleAdd">
    新增
  </el-button>

  <!-- 多个权限（满足任一即可） -->
  <el-button v-hasPermi="['asset:edit', 'asset:admin']" @click="handleEdit">
    编辑
  </el-button>

  <!-- 删除按钮 -->
  <el-button v-hasPermi="['asset:delete']" type="danger" @click="handleDelete">
    删除
  </el-button>
</template>
```

**注意事项**:
- 指令值**必须是数组**
- 使用 `includes` 逻辑（满足任一权限即显示）
- 无权限时元素从 DOM 中**移除**（非隐藏）

## 8.3 角色级权限（v-permission）

```vue
<template>
  <!-- 仅管理员可见 -->
  <div v-permission="['admin']">
    管理员专属内容
  </div>

  <!-- 管理员或财务可见 -->
  <div v-permission="['admin', 'finance']">
    敏感数据
  </div>
</template>
```

## 8.4 权限标识命名规范

权限标识采用 `模块:功能:操作` 格式：

```
asset:list      # 资产列表
asset:create    # 新增资产
asset:edit      # 编辑资产
asset:delete    # 删除资产
asset:export    # 导出资产
asset:admin     # 资产管理（最高权限）
```

### 权限标识命名模板

| 操作 | 权限标识 | 说明 |
|------|----------|------|
| 列表 | module:list | 查看列表 |
| 详情 | module:info | 查看详情 |
| 新增 | module:create | 新增操作 |
| 编辑 | module:edit | 编辑操作 |
| 删除 | module:delete | 删除操作 |
| 导出 | module:export | 导出操作 |
| 导入 | module:import | 导入操作 |
| 管理 | module:admin | 模块管理权限 |

## 8.5 编程式权限判断

```javascript
export default {
  methods: {
    handleAction() {
      // 获取权限列表
      const permissions = this.$store.getters.permissions
      
      // 判断是否有权限
      if (permissions.includes('asset:admin')) {
        // 有权限执行
      } else {
        this.$message.warning('无操作权限')
      }
    }
  }
}
```

## 8.6 权限指令对比

| 指令 | 用途 | 判断方式 | 无权限时 |
|------|------|----------|----------|
| v-hasPermi | 按钮权限 | 权限标识 | 移除 DOM |
| v-permission | 角色权限 | 角色标识 | 移除 DOM |
