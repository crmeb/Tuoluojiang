# 三、目录结构规范

## 3.1 项目目录结构

```
src/
├── api/              # API 接口层
│   ├── request.js    # Axios 封装（核心）
│   ├── user.js       # 用户相关接口
│   └── ...
├── assets/           # 静态资源（图片、字体等）
├── components/       # 全局通用组件
│   ├── common/       # 通用业务组件
│   ├── form-common/  # 表单通用组件
│   ├── form-designer/# 表单设计器
│   └── ...
├── config/           # 业务配置
├── directive/        # 自定义指令
├── filters/          # 全局过滤器
├── icons/            # SVG 图标
├── lang/             # 国际化语言包
├── layout/           # 布局组件
├── libs/             # 工具库（项目级）
├── mixins/           # Vue 混入
├── router/           # 路由配置
├── store/            # Vuex 状态管理
│   ├── modules/      # Store 模块（自动注册）
│   ├── getters.js    # 全局 getters
│   └── index.js      # Store 入口
├── styles/           # 全局样式
├── utils/            # 工具函数
├── views/            # 业务视图
├── App.vue           # 根组件
├── main.js           # 入口文件
├── permission.js     # 路由守卫
└── settings.js       # 全局配置
```

## 3.2 目录职责说明

### api/ - API 接口层

存放所有后端接口定义，每个模块一个文件：

```
api/
├── request.js        # Axios 封装（核心文件，勿随意修改）
├── user.js           # 用户接口
├── asset.js          # 资产接口
├── enterprise.js     # 企业接口
└── ...
```

### components/ - 全局组件

存放可复用的全局组件：

```
components/
├── common/           # 通用业务组件
│   ├── pagination/
│   ├── table/
│   └── search-form/
├── form-common/      # 表单通用组件
├── form-designer/    # 表单设计器
└── ...
```

### directive/ - 自定义指令

存放 Vue 自定义指令：

```
directive/
├── permission.js     # 角色权限指令
├── hasPermi.js       # 按钮权限指令
└── ...
```

### store/ - 状态管理

Vuex Store 模块，支持自动注册：

```
store/
├── modules/          # 模块目录（自动注册）
│   ├── user.js
│   ├── permission.js
│   └── ...
├── getters.js        # 全局 getters
└── index.js          # Store 入口
```

### views/ - 业务视图

存放所有业务页面：

```
views/
├── user/             # 用户模块
├── asset/            # 资产模块
├── setting/          # 设置模块
└── ...
```

## 3.3 业务模块目录结构

每个业务模块遵循以下结构：

```
views/
└── user/                     # 用户模块
    ├── components/           # 模块私有组件
    │   ├── user-form.vue
    │   └── user-detail.vue
    ├── list/
    │   └── index.vue         # 列表页
    ├── detail/
    │   └── index.vue         # 详情页
    └── workbench/
        └── index.vue         # 工作台
```

### 模块目录规范

| 目录/文件 | 说明 | 必需 |
|-----------|------|------|
| `components/` | 模块私有组件 | 可选 |
| `list/index.vue` | 列表页面 | 推荐 |
| `detail/index.vue` | 详情页面 | 可选 |
| `index.vue` | 模块入口 | 可选 |

## 3.4 新增模块规范

新增功能模块时，按以下步骤操作：

### 步骤 1：创建页面文件

在 `src/views/` 下创建模块目录：

```bash
# 创建资产模块
mkdir -p src/views/asset/list
mkdir -p src/views/asset/detail
touch src/views/asset/list/index.vue
touch src/views/asset/detail/index.vue
```

### 步骤 2：创建 API 文件

在 `src/api/` 下创建对应接口文件：

```javascript
// src/api/asset.js
import request from './request'

export function assetListApi(params) {
  return request.get('asset', params)
}

export function assetCreateApi(data) {
  return request.post('asset', data)
}
```

### 步骤 3：配置后端菜单

通过后端管理界面配置菜单（推荐方式）：

| 字段 | 说明 | 示例 |
|------|------|------|
| menu_name | 菜单名称 | 资产管理 |
| menu_path | 菜单路径 | /admin/asset/list |
| component | 组件路径 | asset/list/index |
| icon | 菜单图标 | asset |
| pid | 父菜单ID | 0（一级菜单） |

### 步骤 4：（可选）创建 Store 模块

如果模块需要全局状态管理：

```javascript
// src/store/modules/asset.js
const state = {
  assetList: []
}

const mutations = {
  SET_ASSET_LIST: (state, list) => {
    state.assetList = list
  }
}

const actions = {
  async fetchAssetList({ commit }, params) {
    // ...
  }
}

export default {
  namespaced: true,
  state,
  mutations,
  actions
}
```

## 3.5 文件命名规范

### Vue 组件文件

```
# 使用 kebab-case
user-list.vue        ✅
user-detail.vue      ✅
form-designer.vue    ✅

UserList.vue         ❌
userList.vue         ❌
```

### JavaScript 文件

```
# 使用 camelCase
auth.js              ✅
validators.js        ✅
request.js           ✅

Auth.js              ❌
auth-validators.js   ❌
```

### 样式文件

```
# 使用 kebab-case
variables.scss       ✅
element-variables.scss  ✅
user-list.scss       ✅

Variables.scss       ❌
userList.scss        ❌
```

## 3.6 目录创建示例

完整的新模块创建流程：

```bash
# 1. 创建模块目录
mkdir -p src/views/asset/{list,detail,components}

# 2. 创建页面文件
touch src/views/asset/list/index.vue
touch src/views/asset/detail/index.vue

# 3. 创建私有组件
touch src/views/asset/components/asset-form.vue

# 4. 创建 API 文件
touch src/api/asset.js

# 5. （可选）创建 Store 模块
touch src/store/modules/asset.js
```
