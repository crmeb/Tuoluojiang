# 七、路由配置规范

## 7.1 动态路由（推荐）

大多数业务页面应通过后端菜单配置实现动态路由：

**步骤**:
1. 在 `src/views/` 下创建页面文件
2. 在后端管理界面配置菜单
3. 配置 `component` 字段指向文件路径

**后端菜单配置字段**:

| 字段 | 说明 | 示例 |
|------|------|------|
| menu_name | 菜单名称 | 资产管理 |
| menu_path | 菜单路径 | /admin/asset/list |
| component | 组件路径 | asset/list/index |
| icon | 菜单图标 | asset |
| pid | 父菜单ID | 0（一级菜单） |

## 7.2 静态路由

以下场景使用静态路由：

- 登录页、错误页、公开访问的分享页 → `src/router/routes.js`
- 不需要显示在菜单中的详情页、编辑页 → 按业务模块放到 `src/router/modules/<module>.js`

`src/router/modules/` 下的文件由 `modules/index.js` 通过 `require.context` 自动聚合，新增模块只需新建文件，无需改动 `router/index.js`。

```javascript
// src/router/modules/user.js
const userRouter = {
  path: `${roterPre}/user`,
  name: 'users',
  component: Layout,
  children: [
    {
      path: 'resume',
      component: () => import('@/views/user/resume/index'),
      name: 'resume',
      meta: { title: '我的简历' }
    }
  ]
}
```

## 7.3 路由 Meta 配置

```javascript
{
  path: 'list',
  component: () => import('@/views/asset/list/index'),
  name: 'assetList',
  meta: {
    title: '资产列表',    // 页面标题
    icon: 'asset',        // 菜单图标
    hidden: false         // 是否隐藏菜单
  }
}
```

### Meta 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| title | String | 页面标题，显示在面包屑 |
| icon | String | 菜单图标名称 |
| hidden | Boolean | 是否在菜单中隐藏 |
| activeMenu | String | 高亮的菜单路径（用于详情页） |

## 7.4 路由配置示例

### 一级菜单

```javascript
{
  path: '/asset',
  component: Layout,
  redirect: '/asset/list',
  name: 'Asset',
  meta: { title: '资产管理', icon: 'asset' },
  children: [
    // 子路由
  ]
}
```

### 二级菜单

```javascript
{
  path: 'list',
  component: () => import('@/views/asset/list/index'),
  name: 'AssetList',
  meta: { title: '资产列表', icon: 'list' }
}
```

### 隐藏菜单的详情页

```javascript
{
  path: 'detail/:id',
  component: () => import('@/views/asset/detail/index'),
  name: 'AssetDetail',
  meta: { 
    title: '资产详情',
    hidden: true,
    activeMenu: '/asset/list'  // 高亮列表菜单
  }
}
```
