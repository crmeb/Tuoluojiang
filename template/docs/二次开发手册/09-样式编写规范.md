# 九、样式编写规范

## 9.1 全局样式变量

```scss
// src/styles/variables.scss

// 主题色
$--color-primary: #1890FF;

// 文字色阶
$--color-text01: #303133;  // 主文字
$--color-text02: #606266;  // 次要文字
$--color-text03: #909399;  // 占位文字

// 边框色
$--color-line01: #DCDFE6;
$--color-line02: #E4E7ED;

// 菜单相关
$menuText: #BFCBD9;
$menuActiveText: #409EFF;
$menuBg: #FFF;
$sideBarWidth: 200px;
```

## 9.2 Scoped 样式穿透

```vue
<style lang="scss" scoped>
// ✅ 正确 - 使用 ::v-deep 穿透 scoped
::v-deep .el-table__header {
  background-color: #f5f7fa;
}

::v-deep .el-dialog__body {
  padding: 20px 30px;
}

// ❌ 错误 - scoped 下直接写不生效
.el-table__header {
  background-color: #f5f7fa;
}
</style>
```

## 9.3 类名命名规范

```scss
// 使用 BEM 命名法
.user-list {
  // 块
  &__header {
    // 元素
    display: flex;
  }
  
  &__item {
    // 元素
    padding: 12px;
    
    &--active {
      // 修饰符
      background: #f0f0f0;
    }
  }
}

// 或使用语义化命名
.header-container {}
.search-form {}
.table-wrapper {}
.pagination-wrapper {}
```

## 9.4 样式组织规范

```vue
<style lang="scss" scoped>
// 1. 组件根样式
.user-list {
  padding: 20px;
}

// 2. 布局相关
.header-container {
  display: flex;
  justify-content: space-between;
  margin-bottom: 16px;
}

// 3. Element-UI 组件样式覆盖
::v-deep .el-table {
  .el-table__header {
    background: #f5f7fa;
  }
}

// 4. 工具类
.text-danger {
  color: #ed4014;
}

.text-primary {
  color: #1890ff;
}
</style>
```

## 9.5 主题定制

修改主题色只需编辑 `src/styles/element-variables.scss`：

```scss
// src/styles/element-variables.scss
$--color-primary: #1890ff;  // 修改此值即可全局生效
$--color-success: #19be6b;
$--color-warning: #ff9900;
$--color-danger: #ed4014;

@import '~element-ui/packages/theme-chalk/src/index';
```

## 9.6 常用样式变量

| 变量名 | 用途 | 值 |
|--------|------|-----|
| $--color-primary | 主色调 | #1890FF |
| $--color-success | 成功色 | #19be6b |
| $--color-warning | 警告色 | #ff9900 |
| $--color-danger | 危险色 | #ed4014 |
| $--color-text01 | 主文字 | #303133 |
| $--color-text02 | 次要文字 | #606266 |
| $--color-text03 | 占位文字 | #909399 |
