# API接口目录结构说明

## 目录结构

```
.
├── administration.ts         # 行政管理接口
├── business.ts               # 业务管理接口
├── chart.ts                  # 图表统计接口
├── chatAi.ts                 # AI聊天接口
├── client.ts                 # 客户端接口
├── cloud.ts                  # 云服务接口
├── config.ts                 # 配置管理接口
├── contractSign.ts           # 合同签署接口
├── develop.ts                # 开发工具接口
├── enterprise.ts             # 企业管理接口
├── form.ts                   # 表单管理接口
├── inventory.ts              # 库存管理接口
├── program.ts                # 项目管理接口
├── public.ts                 # 公共接口
├── request.ts                # 请求封装
├── setting.ts                # 设置接口
├── system.ts                 # 系统管理接口
├── user.ts                   # 用户管理接口
└── weCom.ts                  # 企业微信接口
```

## 接口分类说明

### 管理类接口
- administration.ts: 行政管理相关接口
- enterprise.ts: 企业管理相关接口
- user.ts: 用户管理相关接口
- system.ts: 系统管理相关接口

### 业务类接口
- business.ts: 业务流程相关接口
- client.ts: 客户管理相关接口
- form.ts: 表单处理相关接口

### 工具类接口
- chart.ts: 图表统计相关接口
- cloud.ts: 云存储相关接口
- develop.ts: 开发工具相关接口
