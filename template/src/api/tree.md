# API接口目录结构说明

## 目录结构

```
.
├── administration.js         # 行政管理接口
├── business.js               # 业务管理接口
├── chart.js                  # 图表统计接口
├── chatAi.js                 # AI聊天接口
├── client.js                 # 客户端接口
├── cloud.js                  # 云服务接口
├── config.js                 # 配置管理接口
├── contractSign.js           # 合同签署接口
├── develop.js                # 开发工具接口
├── enterprise.js             # 企业管理接口
├── form.js                   # 表单管理接口
├── inventory.js              # 库存管理接口
├── program.js                # 项目管理接口
├── public.js                 # 公共接口
├── request.js                # 请求封装
├── setting.js                # 设置接口
├── system.js                 # 系统管理接口
├── systemForm.js             # 系统表单接口
├── user.js                   # 用户管理接口
└── weCom.js                  # 企业微信接口
```

## 接口分类说明

### 管理类接口
- administration.js: 行政管理相关接口
- enterprise.js: 企业管理相关接口
- user.js: 用户管理相关接口
- system.js: 系统管理相关接口

### 业务类接口
- business.js: 业务流程相关接口
- client.js: 客户管理相关接口
- form.js: 表单处理相关接口

### 工具类接口
- chart.js: 图表统计相关接口
- cloud.js: 云存储相关接口
- develop.js: 开发工具相关接口
