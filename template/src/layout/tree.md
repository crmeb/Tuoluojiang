# 布局组件目录结构说明

## 目录结构

```
.
├── components/               # 布局相关组件
├── mixin/                    # 布局混入功能
└── index.vue                 # 主布局组件
```

## 组件说明

### 主要组件
- index.vue: 应用主布局组件，包含导航、侧边栏等整体布局结构

### 布局组件 (components/)
- 存放布局相关的子组件
- 如头部导航、侧边栏、标签页等界面布局元素

### 混入功能 (mixin/)
- 提供布局相关的通用功能
- 如响应式处理、主题切换等
