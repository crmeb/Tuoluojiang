# 视图页面目录结构说明

## 目录结构

```
.
├── administration/           # 行政管理页面
├── business/                 # 业务管理页面
├── chat/                     # 聊天页面
├── customer/                 # 客户管理页面
├── develop/                  # 开发工具页面
├── error-page/               # 错误页面
├── fd/                       # 表单设计页面
├── hr/                       # 人力资源页面
├── inventory/                # 库存管理页面
├── login/                    # 登录页面
├── program/                  # 项目管理页面
├── search/                   # 搜索页面
├── setting/                  # 设置页面
├── system/                   # 系统管理页面
├── user/                     # 用户管理页面
└── share.vue                 # 分享页面
```

## 页面分类说明

### 管理类页面
- administration/: 行政管理相关页面
- enterprise/: 企业管理相关页面
- hr/: 人力资源管理相关页面
- user/: 用户管理相关页面

### 业务类页面
- business/: 业务流程相关页面
- customer/: 客户管理相关页面
- program/: 项目管理相关页面

### 工具类页面
- develop/: 开发工具相关页面
- fd/: 表单设计相关页面
- system/: 系统管理相关页面
